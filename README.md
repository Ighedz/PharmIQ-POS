🧠 PharmIQ — Smart POS for African Pharmacies

PharmIQ is a modern web-based Pharmacy Point of Sale (POS) system built to empower small and mid-sized community pharmacies across Africa.
It simplifies drug sales, inventory management, profit tracking, and patient safety through real-time interaction checks - all within one intelligent platform.

## 🚧 Project Status
PharmIQ POS is a **work in progress**.  
The MVP version is under active development — new features are being added and existing ones refined.


🚀 Features
🏪 Storefront Management

Create and manage your pharmacy dashboard instantly after registration.

Customize store name and address.

💊 Smart Drug Sales

Add and search drugs in real-time.

Apply discounts and generate printable customized receipts.

Automatically log sales history and compute profit analytics (COGS).

In-built drug–drug interaction checker for patient safety.

📦 Inventory Management

Add new drugs by uploading an image of sales invoice.

Track stock levels and view low-stock alerts.

📊 Analytics Dashboard

Visual breakdown of total sales, cost of goods sold (COGS), and gross profit.

Filter by date, drug, or category.

Track most and least sold drugs



Pharmacists have protected access to their dashboards only.
